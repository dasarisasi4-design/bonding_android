# BONDINGS Native Android starter

This is a native Android UI prototype, not a WebView wrapper. It includes a native 3-column Discover grid, profile preview, Likes, Chat, Profile and Filters screens with sample/demo profiles.

Not yet connected: Supabase authentication, live profiles and photos, real connection requests, real-time chat, moderation, and Play Store release signing. This is a prototype and must not be published as a finished dating app until those items are implemented and tested.

Build: upload all folder contents (including .github) to the repository root. GitHub Actions -> Build BONDINGS Native APK -> Run workflow. Download BONDINGS-native-debug-apk after success.
